## Frozen constraints

- **Barrier-free.** No circuit or fault contains a barrier. Every instruction index in the catalogue
  refers to the barrier-free operation lists of the canonical source; adding barriers would shift
  indices (in C4 the first measurement would move from 43 to 48) without changing outcomes.
- **C4 instruction indices:** initial H 0–2, oracle 1 3–7, diffuser 1 8–22, oracle 2 23–27,
  diffuser 2 28–42, measurements 43–45 (46 instructions).
- Qubit qᵢ is measured into classical bit cᵢ unless a measurement-mapping fault says otherwise; keys
  are written c_{m−1}…c₀.

## Change policy

The canonical source, the manifest and the preflight evidence are not edited. `python -m
evaluation.check_catalogue` fails if the canonical source or any preflight evidence file differs
from the hashes recorded at freeze time. Any change requires mentor approval and a new catalogue
version.

## Refactoring note

No definition was moved or duplicated. `catalogue.py` is imported unchanged as
`evaluation.preflight.catalogue` (an implicit namespace package; no `__init__.py` was added), and
`circuits.py` and `faults.py` only re-expose it. The preflight scripts still import it as a sibling
module, so the preflight evidence remains reproducible as recorded.
